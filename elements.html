Senus Board Report — AI-Native Financial Analytics Platform

Built as a technical assessment for Assiduous Technology, this is a full-stack board reporting platform for Senus PLC, an Irish Natural Capital management company listed on Euronext Access Dublin. Rather than a static report, the app extracts real financial data directly from scanned PDF filings, calculates the metrics a board actually cares about, and layers AI-generated commentary on top.

The backend is a FastAPI service backed by PostgreSQL (via SQLAlchemy and Alembic migrations), storing structured financial data across seven tables. Since the source documents are scanned images rather than text-based PDFs, extraction runs entirely through Claude's vision API instead of traditional PDF parsing — one consistent extraction path, using four purpose-built prompts covering the income statement, balance sheet, cash flow, and growth metrics.

The metrics engine covers all five board-report categories — growth, profitability, cash & liquidity, solvency, and returns — using real figures rather than approximations: EBITDA is built from actual depreciation data, and Debt Service Coverage Ratio uses the company's real loan repayment schedule. A React and Recharts frontend presents it all through a styled dashboard with an AI-generated executive summary panel.

MediAssist — AI Hospital Assistant

Inspired by a real freelance healthcare project, MediAssist is a fully LLM-native hospital appointment assistant powered by the Claude API. Unlike traditional chatbots built on intent classifiers, MediAssist uses Claude's native tool-use to understand patient requests and orchestrate actions in real time — no hard-coded intents, no decision trees.

The system is built as four independent FastAPI microservices containerised with Docker and deployed on Render: a mock appointments API with JWT-based OTP authentication, a ChromaDB retrieval service that performs vector search over a hospital FAQ knowledge base (RAG), a conversation API that manages multi-turn sessions and drives Claude's agentic tool loop, and a React frontend with a real-time chat UI.

Key features include LLM-native conversation management with persistent session state, secure OTP email authentication before exposing any patient data, RAG-based FAQ responses using ChromaDB vector search with ONNX embeddings, appointment viewing and cancellation via authenticated tool calls, and multilingual support — Claude responds in whatever language the patient writes in.
